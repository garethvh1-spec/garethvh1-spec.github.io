Raspberry Pi has rolled out a notable visual refresh for the Pi Desktop, updating the default theme, icons, and overall look of Raspberry Pi OS. If you're running any Pi with a display — a Grafana dashboard, a Home Assistant kiosk, or even just a headless box you occasionally VNC into — this one's relevant.

What's changed

The update brings modernised GTK themes, refreshed system icons, and a cleaner taskbar. It's not a full desktop environment swap — still the familiar lightweight setup built on Wayfire/labwc — but the polish is genuinely noticeable. Think tidier file manager, better contrast, and icons that don't look like they shipped in 2015.

Why homelabbers should care

Plenty of us run Pis headed, at least some of the time. A kiosk-mode Pi 5 driving a wall-mounted dashboard benefits from a cleaner UI when you need to troubleshoot. And if you're using a Pi as a lightweight admin terminal for your rack, a less dated desktop makes the experience marginally less painful. It also signals continued investment in Pi OS as a usable daily-driver OS, not just a headless server platform.

Caveats

This is cosmetic. It won't speed up your Docker containers or fix your DNS. If you run your Pis purely headless via SSH, you can safely ignore this. And as with any OS update, give it a week before applying to anything production — let others find the rough edges first.

What to do

Run sudo apt update && sudo apt full-upgrade on any Pi running the latest Raspberry Pi OS to pull in the changes.
